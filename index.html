App Banca

Aplicación web bancaria construida con Spring Boot + Thymeleaf. Permite autenticación por RUT, visualización de cuentas y movimientos, transferencias entre clientes y paneles diferenciados por rol (USER, GERENTE, SYS_ADMIN).

Java 25 Spring Boot 4.x Spring Security Spring Data JPA Hibernate PostgreSQL (Supabase) Thymeleaf Bootstrap 5 Maven

Características principales

  • Login por RUT y password con Spring Security.
  • Dashboard dinámico por rol: USER, GERENTE y SYS_ADMIN.
  • Transferencias atómicas con @Transactional y doble trazabilidad.
  • Reglas de negocio: sin montos <= 0 y sin saldo negativo en origen.
  • Monitoreo de riesgo alto para movimientos con monto absoluto >= $500.000.

Arquitectura y modelo

  • Estructura en capas MVC: domain, repository, service, controller, dto, config.
  • Entidad User: RUT único para login, password BCrypt, roles y cuentas 1:N.
  • Entidad Account: número de cuenta único, tipo AHORRO/CORRIENTE, saldo decimal.
  • Entidad Movement: UUID, fecha, descripción, monto y saldo resultante.

Seguridad y endpoints

  • Rutas públicas: /login y recursos estáticos.
  • /admin/** solo para SYS_ADMIN. Resto de rutas autenticadas.
  • Endpoints: GET /login, GET /dashboard, GET/POST /transfer, POST /admin/users, POST /logout.
  • Redirección post-login a /dashboard.

Seed, configuración y ejecución

  • Seed automático: admin (RUT 1-9, rol SYS_ADMIN) y usuario de prueba (RUT 12.345.678-9, rol USER).
  • Configuración en src/main/resources/application.properties con datasource y JPA.
  • Ejecución local: ./mvnw clean spring-boot:run o mvnw.cmd clean spring-boot:run.
  • Pruebas: ./mvnw test. App local en http://localhost:8080/login.
